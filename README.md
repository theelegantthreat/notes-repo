# Notas App - Aplicación de Notas Estilo Google Keep

Una aplicación de escritorio para tomar notas de manera rápida y sencilla, con un nuevo sistema de backup automático y mejorado.

## Descripción

Notas es una aplicación minimalista para gestionar tus notas diarias, inspirada en Google Keep. Incluye un nuevo modo de backup que garantiza que tus notas nunca se pierdan.

## ✨ Características

- 📝 Crear, editar y eliminar notas
- 💾 Sistema de backup automático
- 🔄 Sincronización de datos
- 🎨 Interfaz intuitiva y limpia
- 📁 Almacenamiento local seguro
- ⚡ Acceso rápido a tus notas

## 🚀 Instalación

```bash
# Clonar el repositorio
git clone https://github.com/theelegantthreat/notes-repo.git
cd notes-repo

# Instalar dependencias
npm install

# Ejecutar la aplicación
npm start
```

## 💡 Uso

1. Abre la aplicación
2. Haz clic en "Nueva Nota" para crear una nota
3. Escribe tu contenido
4. Las notas se guardan automáticamente
5. El backup se realiza periódicamente

## 🔄 Sistema de Backup

La aplicación incluye un nuevo modo de backup mejorado que:
- Realiza copias automáticas de tus notas
- Permite restaurar notas desde backups anteriores
- Sincroniza tus datos de forma segura
